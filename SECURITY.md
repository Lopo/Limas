# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Lopo/Limas/security/advisories/new)
rather than in a public issue. You will get a reply there, and credit in the
published advisory if you want it.

Fixes ship as a patch release; the advisory is published together with it.

## Supported versions

Only the latest release receives security fixes.
